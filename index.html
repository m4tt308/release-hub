Senza token le chiamate alle API GitHub sono limitate a 60/ora per IP. Con un token (fine-grained, permesso di sola lettura su repository pubblici) il limite sale a 5000/ora. Il token resta solo in questo browser (localStorage) e non viene mai inviato altrove: non condividere link a questa pagina se hai salvato un token con permessi più ampi del necessario.
